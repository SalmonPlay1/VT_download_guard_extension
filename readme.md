## ✨ Главные возможности

* **⚡ Гибридная защита (API-ключ VirusTotal + Автономное ядро)**:
  * **С бесплатным ключом VirusTotal**: мгновенная проверка скачиваемых файлов по базе **72+ облачных антивирусов** (Kaspersky, Dr.Web, ESET, Microsoft, BitDefender и др.) с потоковым расчётом `SHA-256` на лету.
  * **🧬 Автономный режим БЕЗ API-ключа и БЕЗ антивируса на ПК**: собственное 6-модульное ядро расширения (эвристика и YARA-сигнатуры, рентген заголовков `Windows PE` и энтропии, инспектор архивов `.zip / .rar / .7z / .torrent` без распаковки, проверка скрытых команд в `.lnk` + сверка хешей по базам угроз *MalwareBazaar*, *URLhaus*, *ThreatFox* и *CIRCL*).
* **🧠 Умная сводка поведения и Адаптивный Индекс доверия (0–100%)**:
  * Простым языком объясняет, на что именно реагируют антивирусы: отличает опасные стиллеры паролей (`Stealer / RAT / Trojan`) от безопасных игровых фиксов (`OnlineFix`, `Steam_api`, модов и репаков) и строит 5-осевой **Радар факторов риска**.
* **🛡️ Защита буфера обмена (Anti-ClickFix & Clipper Guard)**:
  * Блокирует скрытые вредоносные команды `PowerShell / Win+R / mshta` на фейковых капчах и предупреждает о подмене кошельков или трейд-ссылок в буфере обмена.

  * Анимированный маскот **«Король Кибер-Лосось»** с 6 уникальными эмоциями прямо внутри окна расширения подсвечивает нужные настройки и показывает, как всё устроено.
* **🎨 Глубокая кастомизация и 4 пресета в 1 клик**:
  * Готовые режимы (`⚡ Комфорт`, `🏰 Паранойя`, `🎮 Геймер`, `🍃 Лёгкий`), 10 тем оформления с живыми частицами, перетаскиваемые стикеры, выбор приоритета окон и свои звуковые оповещения.

## 🚀 Установка

### 🌐 Chrome / Яндекс Браузер / Opera / Edge (Chromium)
1. Скачайте архив **`vt_download_guard_extension_v1.3.zip`** из раздела \[suspicious link removed\].
2. Распакуйте архив в любую удобную папку на ПК.
3. Откройте страницу расширений в браузере (`chrome://extensions`, `browser://extensions` или `opera://extensions`).
4. Включите тумблер **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
5. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с распакованными файлами.

### 🦊 Mozilla Firefox
1. Скачайте файл **`vt_download_guard_firefox_v1.3.xpi`** из раздела \[suspicious link removed\].
2. Откройте Firefox, перейдите на страницу `about:addons`, нажмите на иконку шестерёнки ⚙️ и выберите **«Установить дополнение из файла...»** (*Install Add-on From File...*).
