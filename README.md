# VT_download_guard_extension
## Установка расширения

1. Скачайте архив из раздела **Releases** и распакуйте его в удобную папку.
2. Откройте страницу расширений в браузере (например, `chrome://extensions` или `browser://extensions`).
3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с распакованными файлами.
